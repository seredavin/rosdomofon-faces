## ADDED Requirements

### Requirement: Порог узнавания в интерфейсе
Порог сходства, начиная с которого лицо считается принадлежащим человеку из базы,
SHALL задаваться в веб-интерфейсе числом от 0 до 1 и сохраняться между
перезапусками. Если порог в интерфейсе не задан, SHALL использоваться значение по
умолчанию из настройки окружения. Новый порог SHALL применяться ко всем камерам со
следующего распознавания, без перезапуска сервиса.

#### Scenario: Порог повышен
- **WHEN** пользователь повышает порог так, что сходство лица с образцами человека оказывается ниже порога
- **THEN** следующие распознавания этого лица дают «не совпало с базой» без перезапуска сервиса

#### Scenario: Недопустимое значение
- **WHEN** клиент сохраняет порог вне диапазона 0–1
- **THEN** порог не меняется, и API возвращает ошибку

#### Scenario: Сброс к значению по умолчанию
- **WHEN** пользователь сбрасывает порог
- **THEN** действует значение из настройки окружения, а интерфейс показывает его как значение по умолчанию
