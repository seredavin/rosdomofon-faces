## MODIFIED Requirements

### Requirement: Круглосуточный мониторинг выбранных камер
Система SHALL непрерывно получать и анализировать видео с камер, выбранных для
мониторинга, пока сервис запущен и выполнен вход в аккаунт Росдомофона. Набор
камер SHALL задаваться в веб-интерфейсе и сохраняться между перезапусками. Если
набор в интерфейсе не задан, SHALL использоваться значение по умолчанию из
настройки окружения; если не задано и оно, мониторятся все камеры аккаунта.

#### Scenario: Мониторинг стартует вместе с сервисом
- **WHEN** сервис запускается, и сохранённый вход действителен
- **THEN** анализ видео начинается для всех камер мониторинга без открытия страницы

#### Scenario: Мониторинг стартует после входа
- **WHEN** пользователь выполняет вход через веб-интерфейс
- **THEN** анализ видео начинается для всех камер мониторинга

#### Scenario: Выбран не весь список камер
- **WHEN** в настройках отмечена только камера 1001
- **THEN** в фоне анализируется только камера 1001

#### Scenario: Набор из интерфейса важнее значения по умолчанию
- **WHEN** в окружении указана камера 1001, а в интерфейсе выбрана камера 12034
- **THEN** в фоне анализируется только камера 12034, в том числе после перезапуска сервиса

#### Scenario: Сброс к значению по умолчанию
- **WHEN** пользователь сбрасывает набор камер к значению по умолчанию
- **THEN** мониторятся камеры из настройки окружения, а если она не задана — все камеры аккаунта

## ADDED Requirements

### Requirement: Изменение набора камер без перезапуска
Изменение набора камер мониторинга SHALL применяться сразу, без перезапуска
сервиса: добавленные камеры SHALL начинать анализироваться в фоне, исключённые —
переставать анализироваться в фоне; если исключённую камеру в этот момент
смотрят, её анализ SHALL продолжаться до закрытия просмотра. Пустой набор SHALL
быть допустим и означать, что фоновый анализ выключен.

#### Scenario: Камера добавлена в набор
- **WHEN** пользователь отмечает камеру 12034 и сохраняет настройки
- **THEN** анализ камеры 12034 начинается без открытия её видео и без перезапуска сервиса

#### Scenario: Камера исключена из набора
- **WHEN** пользователь снимает отметку с камеры, которую никто не смотрит, и сохраняет настройки
- **THEN** поток этой камеры закрывается, новые события с неё не создаются

#### Scenario: Исключена камера, которую сейчас смотрят
- **WHEN** пользователь исключает камеру, видео которой открыто
- **THEN** видео продолжает показываться, а анализ прекращается вскоре после закрытия просмотра

#### Scenario: Неизвестная камера
- **WHEN** клиент сохраняет набор с камерой, которой нет в аккаунте
- **THEN** настройки не меняются, и API возвращает ошибку с id этой камеры

### Requirement: Настройки мониторинга в интерфейсе
Веб-интерфейс SHALL показывать список камер аккаунта с отметкой, входит ли камера
в набор мониторинга, состоянием её потока (идёт ли анализ, последняя ошибка) и
источником набора (интерфейс или значение по умолчанию). Камеры из набора по
умолчанию, которых нет в аккаунте, SHALL показываться с предупреждением.

#### Scenario: В значении по умолчанию несуществующая камера
- **WHEN** в окружении указана камера 1001, которой нет в аккаунте, и набор в интерфейсе не задан
- **THEN** на вкладке настроек видно предупреждение, что камера 1001 не найдена и мониторинг пуст
