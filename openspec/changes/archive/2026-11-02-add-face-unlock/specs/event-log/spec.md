## ADDED Requirements

### Requirement: Отметка об открытии двери в журнале
Если в ходе появления сработало автоматическое открытие двери, событие SHALL
хранить результат: «открыто», «открыл бы» (режим «только журнал») или «ошибка
открытия». Журнал в интерфейсе и API SHALL показывать этот результат и
позволять отфильтровать события с открытием.

#### Scenario: Открытие в режиме «только журнал»
- **WHEN** человек с разрешением распознан на привязанной камере в режиме «только журнал»
- **THEN** у его события в журнале отметка «открыл бы»

#### Scenario: Фильтр открытий
- **WHEN** пользователь выбирает в журнале фильтр «только с открытием»
- **THEN** показываются только события с отметкой открытия любого вида
